# アーキテクチャ決定記録: `/random`の機能とキャッシュ方針

## ステータス

**確定: 現行のランダム20件一覧を維持し、キャッシュしない**（2026-07-13決定）

## コンテキスト

現行`/random`はランダムな個別名言へ転送するルートではなく、公開済み名言20件の一覧、シャッフル操作、自己canonical、OG、Breadcrumbを持つ独立ページである。個別ページへの302はキャッシュ方式の変更ではなく、機能とSEO仕様の変更になる。

## 決定

- `/random`は現行どおり、公開対象の名言からランダムに20件を選んだ一覧を200で返す。
- シャッフルは同じURLを再取得して別の抽選結果を表示する。
- レスポンスは`Cache-Control: private, no-store`とする。
- Cloudflare Cache Rulesで`/random`を明示的にBypassする。
- canonical、OG、Breadcrumb、sitemap上の`/random`を維持する。
- ランダムな個別名言への302は採用しない。将来変更する場合は機能・SEO変更として別途決定する。

## 検証

- 連続取得がCloudflare HITにならず、結果がエッジで固定化されない。
- 非公開名言が混ざらず、公開件数が20未満の場合も正常表示できる。
- シャッフル操作、canonical、OG、Breadcrumb、sitemapを確認する。
