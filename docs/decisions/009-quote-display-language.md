# アーキテクチャ決定記録: 名言の主表示言語

## ステータス

**確定: 現行の`display_language_preference`仕様を維持する**（2026-07-13決定）

## コンテキスト

`display_language_preference`は閲覧者ごとの言語設定ではなく、各名言について日本語本文と英語本文のどちらを主として表示するかを表すコンテンツ属性である。名称だけでは利用者設定と誤解される可能性があるため、意味とfallbackを明文化する。

## 決定

- 論理的な意味は「名言の主表示言語」とする。
- 値は`ja`または`en`、`NOT NULL`、既定値は`ja`とする。
- 日本語`text`と英語`text_en`の両方がある場合、指定言語を主として表示する。
- 指定側の本文が空の場合は、もう一方の本文へfallbackする。
- SQLite移行時の物理カラム名は`display_language_preference`のまま維持する。
- 管理画面の表示名は「主表示言語」とし、「両言語がある場合の主表示順」であることを説明する。
- HTMLカード、詳細、metadata、OG画像、構造化データは同じ共通resolverを使う。

## 検証

- `ja/en`と`text/text_en`欠損の組み合わせで表示とfallbackを確認する。
- 移行後にNULL・不正値がないことを検査する。
