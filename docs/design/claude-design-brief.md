# Claude Design への依頼文（D8: デザイン刷新）

> claude.ai/design のプロジェクト `meigensyu-redesign` に貼り付ける指示文。
> D8（デザイン刷新の範囲）のデザインガイド作成の起点となる文書。

---

【依頼】名言サイト「名言集.com」の全面デザイン刷新の方向性を提案してください。

## サイト概要

- 日本語の名言ポータルサイト。名言 約1,800件・著者 約770件を、カテゴリ（2階層）・著者・出典・登場人物・職業・国別で回遊できる。
- 読み物中心・SEO流入が主。ユーザー操作は「いいね」ボタンと検索のみ（ログイン・コメント・投稿なし）。

## 前提

- 現行デザインは一切参照せず、ゼロから新しいデザインにする。
- PC・スマホ両対応のレスポンシブ（モバイルファースト推奨）。

## 主要ページ

1. トップ（注目名言＋ランキング抜粋）
2. 名言一覧（ページング）／新着
3. 名言個別ページ（本文・著者・カテゴリ・出典・いいね）← 最重要
4. 著者一覧・著者詳細（職業/国籍/生没年＋その著者の名言一覧）
5. カテゴリ一覧・カテゴリ別名言（2階層）
6. ランキング（名言/著者/カテゴリ）
7. 検索（インクリメンタル検索、入力しながら結果表示）
8. ランダム名言20件＋シャッフルボタン
9. 静的ページ（about/privacy/terms）

## 必要なコンポーネント

- 名言カード（いいねボタン・いいね数付き）/ 著者カード
- カテゴリチップ / パンくず / ページネーション
- 検索ボックス＋結果リスト / ランキングリスト（順位表示）
- ヘッダー・グローバルナビ・フッター（スマホではナビをどう畳むかも提案）

## 技術制約（デザインに影響するもの）

- サーバーサイドレンダリング（Jinja2）+ HTMX。SPAフレームワークは使わない。
- CSSは外部ファイルのみ（CSPによりインラインstyle/script禁止）。
- JSは最小限。JSがなくても成立するデザインが望ましい。
- 日本語Webフォントは重いので、system-ui系フォントスタック前提、または見出しだけのサブセット利用など軽量な提案にしてほしい。
- Cloudflareエッジキャッシュ前提の静的なHTML。凝ったアニメーションより表示速度と可読性を優先。

## デザインで重視したいこと

- 名言（日本語テキスト）が主役。引用文の美しさ・可読性を最優先。
- SEOサイトとしての情報密度とスキャンしやすさの両立。
- 名言個別ページはOG画像でSNSシェアされる想定。

## 依頼内容

1. デザインの方向性を2〜3案（それぞれコンセプト・配色・タイポグラフィ）
2. 選んだ案でのデザイントークン（色・フォント・サイズ・余白のスケール）
3. 主要コンポーネント一式
4. 代表3ページ（トップ・名言個別・名言一覧）のPC/モバイルレイアウト

## 未決事項（提案がほしい点）
